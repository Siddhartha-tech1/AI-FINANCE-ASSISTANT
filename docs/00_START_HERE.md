# AI Finance Assistant — Simple Project Docs

This is a deliberately small documentation set. It follows the AI Finance Assistant SRS and your BudgetPlanner screenshot.

## Files
- `01_PRD.md` — What the application should do.
- `02_TECHNICAL_OVERVIEW.md` — Technology stack and simple architecture.
- `03_DATABASE.md` — MongoDB collections and fields.
- `04_API_SPEC.md` — Backend endpoints.
- `05_UI_SPEC.md` — Pages and visual design.
- `06_ML_FEATURES.md` — Expense categorization and spending estimate.
- `07_AGENTS.md` — Working rules for Codex.
- `README.md` — Local setup guide.
- `08_DEVELOPMENT_STEPS.md` — Build order and basic testing checklist.

## Keep it simple
Build only the features in the SRS. Do not add payment processing, bank connections, upcoming payments, savings goals, admin dashboard, or deployment work unless requested later.

## How to use
Put these files in the project root (or put all except `07_AGENTS.md` and `README.md` inside `docs/`). Keep `AGENTS.md` in the root so Codex can follow it.
