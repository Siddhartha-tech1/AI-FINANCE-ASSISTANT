# UI / UX Specification

## Visual reference
Use the user's uploaded BudgetPlanner screenshot as the visual reference. Recreate its general layout and feel; do not copy its brand name or sample data.

## Look and feel
- Dark fintech dashboard.
- Black/dark charcoal cards and content area.
- Deep purple gradient page background.
- Violet/blue highlights.
- Green for income and positive changes.
- Red/coral for expenses and warnings.
- Thin borders, rounded cards, clean typography.
- Minimal animations; prioritize clarity and working features.

## Main layout
- Left vertical icon sidebar.
- Top header with app name, navigation, search/profile controls.
- Main content with a responsive two-column dashboard layout.

## Pages
1. Login
2. Register
3. Overview / Dashboard
4. Transactions
5. Budgets
6. Analytics
7. AI Insights
8. Finance Chat
9. Profile

## Dashboard content
- Four summary cards: Balance, Income, Expenses, Budget Remaining.
- Main monthly income/expense trend chart.
- Category-wise expense donut chart and category list.
- Recent transactions table.
- Budget progress cards.
- Small AI insights panel.

## Transactions page
- Add transaction button/form.
- Table with description, amount, date, type, category, actions.
- Search and filters for date, category, and type.
- Allow user to correct suggested category.

## Budgets page
- Monthly total budget.
- Optional category limits.
- Spent, remaining, and percentage used.
- Warning when budget is nearly used or exceeded.

## Responsive behavior
- Desktop: sidebar and two-column dashboard.
- Mobile: collapsible navigation and vertically stacked cards.
- Tables should become scrollable or compact cards.
- Include loading, empty, and error states.

## Keep out of first version
Do not build upcoming payments, savings goals, or other features not required by the SRS.
