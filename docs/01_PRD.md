# Product Requirements — AI Finance Assistant

## Purpose
A simple personal finance application where a user records income and expenses, tracks budgets, views spending charts, and receives basic ML-based categorization and financial insights.

## Main user
A registered user managing their own finances.

## Features required
1. Register, log in, and log out.
2. Add, view, edit, and delete income and expense transactions.
3. Suggest an expense category from its description using ML.
4. Let the user change an incorrect suggested category.
5. Create a monthly budget and optional category budgets.
6. Show income, expenses, balance, and category-wise spending.
7. Show monthly spending trends.
8. Estimate future spending when enough history exists.
9. Show simple, explainable financial insights.
10. Provide a basic chatbot for questions about the user's own recorded finance data and app features.

## Categories
Food, Transport, Shopping, Bills, Entertainment, Health, Education, Other.

## Not included
- Bank account connections.
- Money transfers or payment processing.
- Stock/investment recommendations.
- Tax filing or professional financial advice.
- Upcoming payments and savings goals in the first version.

## Success checklist
- A user can register and use the app.
- Users can only see their own records.
- Transaction and budget calculations are correct.
- Dashboard charts use real database data.
- ML category suggestions can be corrected.
- Forecasts are clearly marked as estimates.
- The app explains when there is not enough data.

## Important note
This is an educational project, not professional financial advice.
